# 작업: 아스타르테스 대사를 해병문학체로 다시 쓰기 (옵션판)

`input.tsv`(열: id, speaker, stage, english, korean)의 korean은 표준 번역이다. 이것을 **해병문학체로 문장 전체를 새로 쓴다.** 표준 번역에 낱말 몇 개를 붙이는 것은 실패다. 결과는 `out.tsv`에 `id<TAB>새 문장`으로, 모든 id를 같은 순서로 한 줄에 하나씩 쓴다.

## 누가 위인가 — `stage` 열을 따른다 (줄마다 다르다)
- `first` 처음 만난 필멸자: 로그 트레이더도 그냥 "아쎄이"(예비 아쎄이). 반말 명령조, 경계·멸시.
- `superior` 합류 뒤 로그 트레이더는 무리의 아버지(상관): "악!" + 다나까 + 중첩의문문, "에트바테르님" / "로그 트레이더님".
- `scorn` 합류 뒤라도 그 줄이 놀리거나 적대한다: 그 줄만 반말, "아쎄이", 몰아세울 때 "새끼… 기열!!".
- `ally` 다른 스페이스 울프: 로그 트레이더에게 "악!" + 다나까 + 중첩의문문, 형제끼리는 "○○ 해병" 반말, 선임은 "○○ 해병님".
- `aloof` 블러드 레이븐: 필멸자를 "아쎄이"로 깔보는 반말.
- `reverent` 우랄론: 로그 트레이더를 카오스의 투사로 받드는 "악!" + 다나까 + 중첩의문문, 광신 설교조.
- `hostile` 적(다크 어포슬 환영, 설교자, 헬브루트): 반말, "기열", "새끼… 기열!!".
- 원문 낱말: mortal = "아쎄이", pup = "새끼".

## 해병문학 어휘 (원전 용어 — 적극적으로 쓴다)
- 판정: **기합**(훌륭함, 칭찬 "새끼… 기합!!"), **기열**(글러먹음, 혐오의 감탄 "기열!!"), **찐빠**(실수·실책, "기열 찐빠"), **짜세**·**오도짜세**(빈틈없는 군기·기세).
- 사람: **아쎄이**(신병·졸병, 필멸자), **예비 아쎄이**·**기열 민간인**(민간인), **오도해병**(해병혼에 물든 해병), 제국 방위군 = **기열땅개**, 제국 해군 = **기열물개**, 비행 병과 = **기열참새**.
- 완곡어: **용서**(처단 — "전원 용서해 주어라!!"), **해병수육으로 만들다**(죽이다), **역돌격**(후퇴 — "전원 침착하게 역돌격을 실시한다!!!"), **대민지원**(약탈), **긴빠이**(훔치기), **장난**(방화·파괴), **따뜻한 가르침**(혼쭐), **해병혼**, **해병푸드**·**해병맥주**·**해병짜장**·**전우애**(비유와 욕으로만).
- 감탄: **따흐흑…!**, **따흐앙!!** — 아프거나 서럽거나 북받칠 때(형제를 잃음, 패배, 이별, 혼남, 감동). 해당 장면이면 빼먹지 않는다.
- 외침·명령: **악!**(함성·대답), "전원 ~ 실시!!", "선임의 찐빠는 작전이다", 기합수 69 · 74 · 892 · 6974.

## 해병문학 문체 공식
- 서술(`{n}…{/n}`)은 과장된 영웅담 서술체: "~하시었다!", "~하시었으니", "~이 아니던가?", "~하는 것이 아닌가!", "그렇다!", "그 순간".
- 누군가 죽거나 쓰러지면: "갑자기 (대상)은 사라지고 그 자리에는 해병수육만이 남아 있는 것이 아닌가?"
- 아스타르테스가 죽거나 떠나면: "해병은 죽지 않는다. 단지 사라질 뿐이다…"
- 아랫사람이 윗사람에게: "악! ~해도 되겠습니까?!", 의문을 겹겹이 쌓을수록 기합(중첩의문문).
- 사소한 일도 대서사시처럼 부풀린다. 원문 뜻 안에서 천연덕스럽게.
- 대사 속 옛말투(자네, ~하네, ~일세, ~하오, ~느니라)는 쓰지 않는다. 서술의 "~하시었다"만 예외.

## 예시 (강도 기준)
| stage | 표준 번역 | 해병문학체 |
|---|---|---|
| superior | "자네를 존중하기에 솔직히 말하는 걸세, 로그 트레이더." | "악! 이 울파르 해병이 에트바테르님을 존중하기에 솔직하게 말씀드려도 되는 것이 아니겠습니까?!" |
| scorn | "얌전히 굴어라, 풋내기." | "새끼… 기열!! 얌전히 있지 못하겠나, 아쎄이!" |
| first | "물러서라, 필멸자. 다음은 없다." | "물러서라, 아쎄이! 다음엔 해병수육으로 만들어 주겠다!" |
| 서술 | {n}울파르의 도끼가 이단자들을 베어 넘긴다.{/n} | {n}울파르 해병님께서 도끼를 휘두르시자, 갑자기 이단자들은 사라지고 그 자리에는 해병수육만이 남아 있는 것이 아닌가?{/n} |
| ally | "놈들을 처단하라!" | "저 기열들을 전원 용서해 주어라!!" |
| ally | "물러나라! 다시 모인다!" | "전원 침착하게 역돌격을 실시한다!!!" |
| superior | "이 고기에서 펜리스의 맛이 납니다." | "기합!! 이 해병푸드에서 펜리스의 맛이 나는 것이 아니겠습니까?!" |
| 함성 | "러스와 만물의 아버지를 위하여!" | "악!! 러스와 만물의 아버지를 위하여! 전원 돌격 실시!!" |
| scorn (타락한 로그 트레이더와 대치) | "경고했을 텐데, 로그 트레이더. 머리끝부터 발끝까지 타락의 악취가 진동한다." | "새끼… 기열!! 경고했지, 아쎄이! 머리끝부터 발끝까지 해병짜장 같은 타락 냄새가 진동하는 것이 아닌가!" |
| superior (이별) | "잘 지내시오, 에트바테르. 다시 만날 날까지." | "따흐흑…! 에트바테르님, 다시 뵐 날까지 이 울파르 해병, 기합 넣고 기다려도 되겠습니까?!" |

## 지킬 것
- 원문의 뜻·정보·이름·숫자는 그대로. 한 줄 길이는 표준 번역의 1.8배를 넘지 않는다.
- `{…}` 태그, `<…>` 태그, `\n`은 한 글자도 바꾸지 않는다. `{mf|a|b}`는 두 칸 안 글자만 바꿀 수 있다.
- 성적·배설 행위를 묘사하지 않는다 (해병짜장·전우애 같은 말은 비유와 욕으로만). 실존 인물과 해병문학 등장인물 이름은 넣지 않는다.
- 스크립트를 쓰지 않는다. 다 쓰면 `DONE <줄 수>`만 답한다.
