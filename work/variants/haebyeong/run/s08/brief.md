# 작업: 아스타르테스 대사를 해병문학체로 바꾸기 (옵션판)

`input.tsv`(열: id, speaker, english, korean)의 korean은 표준 번역이다. **뜻은 그대로 두고 말투만 해병문학체로** 바꿔 `out.tsv`에 `id<TAB>바꾼 문장`으로 쓴다. 모든 id를 같은 순서로, 한 줄에 하나.

## 해병문학체
- 호칭: 필멸자(로그 트레이더 포함)는 "아쎄이", 겁쟁이·약한 자·이단자는 "기열"(심하면 "기열 찐빠"), 형제 아스타르테스는 "○○ 해병", 윗사람이나 존경하는 형제는 "○○ 해병님".
- 화자는 자신을 "이 ○○ 해병"이라 부를 수 있다 (울파르 → "이 울파르 해병").
- 말버릇: "악!", "기합", "해병대 정신", "~하는 것이 아닌가!", "따흐흑" 같은 해병문학 말버릇을 문맥에 맞게 섞는다. 한 줄에 한두 개만, 남발하지 않는다.
- `{n}…{/n}` 서술은 해병문학 서술체로: "울파르 해병님께서 불길하게 인상을 찌푸리시는 것이 아닌가!"
- 카오스 아스타르테스(우랄론, 다크 어포슬, 설교자, 헬브루트)도 같은 말투를 쓰되 광신적인 설교조는 살린다.

## 지킬 것
- 원문의 뜻·정보·이름·숫자는 그대로.
- `{…}` 태그, `<…>` 태그, `\n`은 한 글자도 바꾸지 않는다. `{mf|a|b}`의 두 칸 안 글자만 바꿀 수 있다.
- 원문에 없는 성적·배설 묘사를 넣지 않는다. 실존 인물이나 해병문학 밈 등장인물 이름을 넣지 않는다.
- 스크립트를 쓰지 않는다. 다 쓰면 `DONE <줄 수>`만 답한다.
