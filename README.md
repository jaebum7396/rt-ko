# 로그 트레이더 한글패치 (새 번역)

**Warhammer 40,000: Rogue Trader** 비공식 한글패치입니다. 게임 **1.6.1.514** (본편 + DLC 1~3) 기준으로, 게임 텍스트 75,411줄 전부를 같은 원칙으로 새로 번역했습니다.

- **일반판**: 기본 번역
- **해병문학체판**: 아스타르테스(스페이스 마린)의 대사만 해병문학체로 바꾼 판. 나머지는 일반판과 같습니다.

> 다운로드: (공개 시 릴리스 링크)

## 설치 방법

1. **기존 한글패치의 자동 갱신 모드를 지웁니다.** 게임을 켤 때마다 번역 파일을 자기 것으로 덮어쓰기 때문입니다.
   `%USERPROFILE%\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager\KoreanPatch_AutoUpdate` 폴더 삭제
2. **한글 글꼴 모드(FontKorean)가 필요합니다.** 기존 한글패치를 쓰고 있었다면 이미 설치돼 있으니 그대로 두면 됩니다. 없다면 [기존 한글패치 릴리스](https://github.com/geungogma/RogueTrader-KoreanPatch/releases)에서 `FontKorean.zip`을 받아 위 `UnityModManager` 폴더 안에 `FontKorean` 폴더째 넣습니다.
3. 게임 폴더의 `WH40KRT_Data\StreamingAssets\Localization\enGB.json`을 백업한 뒤, 받은 `enGB.json`(일반판 또는 해병문학체판)으로 바꿉니다.
   (스팀: 라이브러리에서 게임 우클릭 → 관리 → 로컬 파일 보기)
4. 게임 언어를 **English**로 둡니다. 한국어가 영어 칸에 들어가 있습니다.

### 되돌리기 · 게임 업데이트 뒤
- 되돌리려면 백업한 `enGB.json`을 다시 넣거나, 스팀에서 **게임 파일 무결성 검사**를 하면 원래 영어로 돌아옵니다.
- 게임이 업데이트되면 `enGB.json`이 원래대로 돌아오므로 다시 넣어야 합니다. 업데이트로 바뀐 문장은 새 판이 나올 때까지 영어로 보일 수 있습니다.

## 어떻게 번역했나

1. **원문과 맥락 추출** — 게임에 들어 있는 Owlcat 공식 모드 템플릿에서 줄마다 **화자와 장면(대화) 위치**를 함께 뽑았습니다.
2. **번역 원칙** ([STYLE.md](STYLE.md)) — 직역보다 자연스러운 한국어(의역 허용, 정보는 그대로), 인물별 말투 고정, 상대에 따른 높임, 아이템·기술 이름과 설명까지 전부 번역.
3. **용어집·말투표** — 용어 후보 1,621개를 나무위키 등 국내 커뮤니티 표기와 대조해 정하고, 화자 170명의 말투를 정했습니다. 사람이 한 번 검토했습니다.
4. **장면 단위 번역** — 대화를 장면째 묶어 약 6천 단어씩 298묶음으로 나누고, 묶음마다 해당 용어와 말투만 붙여 AI(OpenAI GPT-6 Astra)가 번역했습니다. 메뉴의 이름(1차)을 먼저 번역해 대사(2차)에 같은 이름을 쓰게 했습니다.
5. **자동 검사와 재번역** — 모든 줄의 게임 태그(`{g}`, `{mf}`, `{name}` 등)·변수·줄바꿈·HTML 태그를 스크립트로 전수 검사하고, 걸린 줄만 다시 번역했습니다. 파이프라인 설계·검사·관리는 Claude(Anthropic)가 맡았습니다.

**AI 번역입니다.** 사람이 모든 줄을 손으로 다듬은 번역은 아니라, 어색한 문장이 남아 있을 수 있습니다. 발견하면 알려 주세요 (원문 한 줄이나 스크린샷).
